# Kenya Public Money Tracker (PMTS)

A web platform that makes information about publicly funded development
projects in Kenya easier to find, understand, and question.

## What it does
- Browse and search government-funded projects
- View approved budgets and reported expenditure, with sources
- Follow implementation milestones and progress
- Submit citizen observations for independent review

## Principles
- Missing data is never shown as zero.
- Budget, commitments, and expenditure are different figures.
- A citizen report is an observation, not an established fact.
- Every record keeps its source and verification status.

## Tech stack
- Backend: Python, FastAPI, PostgreSQL
- Frontend: React, TypeScript

## Repository layout
- `backend/`: FastAPI application
- `frontend/`: React application
- `docs/`: requirements, architecture, database and API docs
