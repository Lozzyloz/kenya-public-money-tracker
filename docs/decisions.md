# Project Decisions

Status: draft, to be agreed by both team members.

## Pilot county
Undecided: Nairobi or Tharaka-Nithi. To be chosen after data research.
The schema treats county as a data row, so the choice does not affect design.

## User roles
- admin: manages projects, budgets, milestones, documents, users
- reviewer: reviews citizen reports, sets verification status; cannot edit official data
- citizen: optional account; public browsing requires no account

## MVP scope (in)
Project directory and profiles, budgets and expenditure with sources,
milestones and progress updates, citizen reports with evidence,
admin dashboard, authentication, report review.

## Out of MVP
Maps, county comparisons, notifications, automated imports, AI features.

## Citizen reports
Anonymous submissions allowed. Contact details optional and never public.
